# shan

Sandbox repository for trying out dsh-superagent.

## How to try it

1. Open an Issue and mention `@shan1719` with one concrete request, for example:
   > Add a line to README.md that says: hello from dsh-superagent.
2. dsh-superagent opens a Ticket, works in its own Ticket directory, and replies in the Issue with a pull request.
3. A mention that reaches no allowed account, or work nobody asked for, does nothing.

## Notes

- Every comment and commit here appears under the `shan1719` account.
- Pull requests are merged by a person, not by the agent.
